In your terminal

gloss is a single binary for macOS, Linux, and Windows. Pictures are drawn with Kitty graphics where the terminal has them, and with glyphs everywhere else. Drop files on it, browse folders, and export what you see.

Homebrew$ brew install --cask nimblemarkets/tap/gloss
Go$ go install github.com/NimbleMarkets/gloss/cmd/gloss@latest

Beyond the demo

The terminal demo above shows the interactive side. gloss is scriptable too:

  • $ cat drawing.svg | glossPipes and stdin are first-class inputs.
  • $ curl -sS -o - https://gristlabs.github.io/grist-static/investment-research.grist | gloss --type gristA document straight from the web: stdin, with --type naming the format.
  • $ gloss --output page.png --page 3 report.pdfExport a page, image, or diagram as a PNG — no UI, for scripts and agents.
  • $ gloss --view all --output sheet.png model.stlSix named views of a mesh in one sheet.
  • $ gloss --serve --pick --prompt "The invoice, please"Ask for a file from a program; the chosen paths are printed to stdout.

For your agents

gloss carries a skill that teaches an AI coding agent to use it: read a file’s text, see a page, diagram, or model as a PNG sized for its vision budget, learn a file’s details as JSON, and ask you for a file when it needs one. Install it for the agents on your machine, from the binary or from the repository:

With gloss$ gloss --skill --install
With npx$ npx skills add NimbleMarkets/gloss
